    How to use a demo

    Run an app

    1. Press Copy URL on the card of an app. The zip of an app ends with _app.zip or _edu_app.zip.
    2. Import the URL with the Fearless manager.
    3. The app is a project of the manager. Run the project.

    Use a library

    1. Press Copy URL on the card of a library. The zip of a library ends with _lib.zip or _edu_lib.zip.
    2. Import the URL into a Fearless project with the Fearless manager.
    3. The import adds the library to the project.

    The zip also works by hand. Put the zip of an app alone in an empty folder and import the folder. Copy the zip of a library, unzipped or not, into a Fearless project.

    The part _edu_ in the name of a zip marks an educational demo: a demo designed to teach programming in Fearless.

    Ranks

    Every demo has a rank: one of these eight names followed by three digits, for example core120 or app999.

    1. base
    2. core
    3. driver
    4. worker
    5. framework
    6. accumulator
    7. tool
    8. app

    The names are ordered from base, the lowest, to app, the highest.

    A library is used by code of a higher rank.

    A demo with rank app and any three digits is a program. Every other rank is a library.

    Add your demo

    Add one file named demos/<id>.json to the repository with a pull request. The next deployment of the site lists the demo.

    {
  "title": "Lights Out",
  "summary": "One or two sentences.",
  "rank": "app999",
  "tags": ["game", "puzzle", "gui"],
  "download": "https://example.org/lights_out/lights_out_app.zip",
  "page": "https://example.org/lights_out/",
  "image": "https://example.org/lights_out/picture.png"
}
    • The fields title, summary, rank, tags and download are required. The fields page and image are optional.
    • The id is the name of the file without .json: lowercase letters, digits and underscores, starting with a letter.
    • A tag is made of lowercase letters, digits and single spaces.
    • The fields download, page and image are https URLs. The button Copy URL copies the URL in download.
    • The zip named by download ends with _app.zip or _edu_app.zip for the rank app, and with _lib.zip or _edu_lib.zip for any other rank.
